# FgIR
FgIR is ML model for functional group present from the IR spectra.

## Prerequisite:
- [nistchempy](https://pypi.org/project/nistchempy/) v.0.2.3 
- [rdkit](https://www.rdkit.org/docs/Install.html) v.2026.03.1
- [CuML-cu12](https://github.com/rapidsai/cuml) v.26.4.0
- [requests](https://pypi.org/project/requests/) v.2.33.1 (*optional, use to receive telegram notification for successful jobs. Can be disabled by removing any <u>notify</u> lines*)

## Output:
- **jdx_files/** to store all NIST scrapped data.
    - **IR_spec_all** 
    - **absorbance** only for IR absorbance spectra.
- **moldataset.csv** is all extracted information of NIST molecule,
- **XYfeature.csv** is for input feature data (intensity for each point of wavenumbers)
- **INCHILabel.txt** storing molecule information in form of INCHI code.
- **label_fg_count.csv** and **label_fg_present.csv** is the label information, based on the number of appearance or simply present (1 or 0).
- **XYnorm.csv** and/or **XYsnv.csv** for any desired normalization. (rec: SNV)


The program workflow are as follow:

## 1. JDX scrapping from NIST
*jdxscrapping*
All the molecules that are in gas phase and has IR spectra are obtained.
> Output: Directory for all IR obtained in JDX scrapping.

## 2. Collect only absorption data
*collectabs*
From all collected IR spectra, it further selected to be the only one with absorption spectra.
> Output: Directory with all copied JDX file for absorbance IR. ~~Filename is in INCHI.~~

## 3. Read needed information from the JCamp file and interpolate data
    *readjcamp* (run automatically with *collectpoint*)
    Information such as wavelength, intensity, molecule name, CAS number, INCHI, etc.
    Output: *moldataset.csv* for all the list extracted information.

*collectpoint*
All the intensity vs wavelength data are collected. Wavelength is interpolated by cubic spline interpolation to have uniform number of data and range.
Range of interpolation can be changed here.
> Output: *XYfeature.csv* and *INCHIlabel.txt* 

## 4. Identify functional group presence with RDkit
*obtainfuncgrouplabel*
From collected INCHI, it put into RDkit to determine its molecule and functional groups that are in the molecules. It collected both as presence and count (how much certain functional groups appear under same molecule)
> Output: *label_fg_count.csv* and *label_fb_presense.csv*

## 5. Normalize the XYfeature
*getxynorm*
Here, Standard Normal Variate (SNV) are used. It is found to help IR spectra more easily identified. Several other methods are prepared (min-max, min-max+SNV).
> Input: XYfeature.csv
> Output: *XYsnv*, *XYnorm*. ~~and *XYsnvnorm*.~~

## 6. Randomforest GridsearchCV
Select label that want to be removed are done here. By default, randfor_gpu_grid will do all posible permutation when tuning hyperparameters. Use *randfor_gpu_random* for using random grid search method. 

*randfor_gpu_grid.py*
Use manual cross validation with F1-score drop train-test as a evaluator.
This file done all: CV for hyperparam tuning, testing, and dumping; it scan through all functional groups.
Output: 
- Main information (accuracy, F1-drop, etc): *randfor_performance.csv*
- CV_report/ for individual FG test result, including F1-score each class.
- confusion_matrix/ for individual FG test result.
- pickled_model/ is the model generated by joblib based on best hyperparameter for all FG.

*plot_feature_importance.py*
Added to plot feature importance value.

## 7. Predict with saved model
> Preparation:
> FTIR Spectra data (digitized/experiment). 
> Spectra need to be in absorbance. If its transmittance, convert by A=-log10(T/Tmax). If its Transmittance obtained from experiment, convert by A=-log10(%T/100).
> Use *getxynorm_ftir* to first normalized your FTIR (absorbance) spectra.
> It can be normalized based on your choice (max/SNV).
> Header are wavenumber, index are samples.

*rfpredict.py*
Use pickled model to make prediction of functional group from the FTIR spectrum

## 8. Threshold Tuning
> Use this to manually tune threshold from default 0.5.
> Tuning from 0.05 to 0.95 with 0.01 step.
> Input: pickled model from step 6, and selected FG in question.

*threshold_tuning.py* Added to do manual tuning for specified model.
